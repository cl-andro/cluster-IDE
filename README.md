Build scripts to produce freely-licensed clusterIDE binaries from [Microsoft's vscode](https://github.com/microsoft/vscode) source. Telemetry disabled. MIT licensed.

## Download

[Stable](https://github.com/cl-andro/cluster-IDE/releases) · [Insiders](https://github.com/cl-andro/cluster-IDE-insiders/releases)

## Build

See `.github/workflows/` for CI build pipelines. Manual trigger via `workflow_dispatch`.

## Supported Platforms

- macOS (x64, arm64) — zip, dmg
- GNU/Linux (x64, arm64, riscv64, ppc64le) — deb, rpm, AppImage, tar.gz
- Windows (x64, arm64)
