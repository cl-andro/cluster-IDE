## <a id="reh"></a>What are reh and reh-web archives?

- Remote Host (`reh`) is the server component for remote ssh/wsl which runs it on a "remote" computer and makes that remote computer accessible via clusterIDE.
- Web Host (`reh-web`) is the server component of the command `cluster serve-web` which runs it locally and makes clusterIDE accessible via a browser.
